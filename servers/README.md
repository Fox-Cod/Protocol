# Свои серверы для Protocol

> ⚠️ **Открытая версия Protocol урезана: серверов автора в ней нет.**
> Адреса раздачи базы, счётчика запусков и прокси ИИ в коде пустые. Серверы
> автора оплачивает автор, и пользоваться ими из своих сборок **нельзя** —
> ни подставлять их адреса, ни доставать их из официального `Protocol.exe`.
> Нужны онлайн-функции — поднимите свои серверы по инструкции ниже. Это
> бесплатно в пределах тарифа Cloudflare Workers; за ИИ вы платите своему
> провайдеру сами.

## Что работает без своих серверов

| | Без серверов | Что нужно |
|---|---|---|
| Законы, поиск, избранное, заметки, Bodycam | ✅ работают | ничего: база встроена в `app/data` |
| Кнопка «Обновить базу» | ❌ «сервер базы не настроен» | свой сервер базы (ниже) |
| ИИ-помощник, быстрый ИИ (Alt+Q), аудит законов | ❌ выключены | свой прокси ИИ (ниже) |
| Счётчик запусков | выключен | не нужен |
| Автообновление программы | смотрит выпуски `Fox-Cod/Protocol` | поменяйте `REPO` в `main.js` на свой репозиторий |

Оба образца — для [Cloudflare Workers](https://workers.cloudflare.com).
Понадобятся бесплатный аккаунт Cloudflare и Node.js. Деплой — через `wrangler`:

```bash
npm install -g wrangler
wrangler login
```

## 1. Прокси ИИ — `servers/ai-proxy/`

Принимает от приложения `POST {system, user, model}` с заголовком
`x-app-secret`, спрашивает модель OpenAI и отвечает `{text}`. Ключ модели
хранится в секретах воркера, в приложение он не попадает.

```bash
cd servers/ai-proxy
wrangler secret put OPENAI_API_KEY     # ваш ключ OpenAI
wrangler secret put APP_SECRET         # длинный случайный пароль, 32+ символа
wrangler deploy
```

`wrangler deploy` напишет адрес вида `https://protocol-ai.<ваш-аккаунт>.workers.dev`.
Дальше — в приложение:

1. Скопируйте `app/ai_config.example.js` в `app/ai_config.js`.
2. `PROXY_URL` — адрес воркера, `APP_SECRET` — тот же пароль, `MODEL` — модель из `ALLOWED_MODELS` в `wrangler.toml`.
3. `npm start` — ИИ заработает.

> ⚠️ **Защитите свой баланс.** Пароль из `ai_config.js` попадает в собранный
> `.exe`, и его оттуда достанут. Поэтому:
> - в кабинете OpenAI поставьте **предел расходов** (Settings → Limits → Budget). Это главная защита;
> - в Cloudflare добавьте правило **Rate limiting** на адрес воркера, например
>   30 запросов в минуту с одного IP;
> - раздаёте свою сборку другим — помните, что их запросы оплачиваете вы.

## 2. Раздача базы — `servers/data/`

Отдаёт приложению `manifest.json` и `<сервер>.json` из папки `data/`
вашего репозитория на GitHub.

1. Сделайте форк [Fox-Cod/Protocol-Data](https://github.com/Fox-Cod/Protocol-Data)
   или свой репозиторий с той же раскладкой: `data/manifest.json` и `data/<сервер>.json`.
2. В `servers/data/wrangler.toml` впишите `DATA_REPO = "ваше-имя/Protocol-Data"`.
3. Пароль по желанию — данные всё равно публичные:
   ```bash
   cd servers/data
   wrangler secret put APP_SECRET        # можно пропустить
   wrangler deploy
   ```
4. В `app/main.js`: `DATA_WORKER_URL` — адрес воркера, `DATA_APP_SECRET` — пароль
   (или `''`, если не задавали).

> ⚠️ **Никогда не выкладывайте `manifest.json` с `"servers": {}`.** Это не
> «пустое обновление», а поломка: список серверов обнулится. Приложение такой
> манифест не примет, но и обновления не получит.

Формат файлов — как в `app/data`: `parts → chapters → articles`, статья
`{num, title, parts:[{n, t}]}`, `num` — строка. В манифесте `updated` — дата
и время сборки базы: приложение обновляется, когда она новее своей.

## 3. Счётчик запусков

В открытой версии выключен (`STATS_WORKER_URL = ''`) и не нужен. Хотите
считать своих пользователей — пишите свой. Помните: номер установки
не должен уходить наружу в открытом виде.

## Своя сборка — что ещё поменять

В `main.js`:

- **`REPO`** — откуда приходят обновления (`владелец/репозиторий` на GitHub с
  выпусками `Protocol.exe`). Оставите как есть — ваша сборка обновится до
  официальной;
- **`DATA_WORKER_URL`, `DATA_APP_SECRET`** — ваш сервер базы;
- **`STATS_WORKER_URL`** — оставьте пустым.

В `package.json` — `productName`, `appId` и **`name`**. От `name` зависит
папка данных `%APPDATA%\<name>`: заметки, избранное, чаты, скачанная база.
С тем же `"protokol"` ваша сборка и официальная делили бы одну папку и
затирали бы друг другу настройки, так что смените его на своё.
