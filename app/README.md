# Protocol — исходный код приложения

Справочник законов серверов Majestic RP с ИИ-помощником и Bodycam — разбором
задержания по звуку. Это код настольного приложения для Windows (Electron).
Готовая программа — на [странице выпусков](https://github.com/Fox-Cod/Protocol/releases);
собирать её самому не нужно, если вы просто играете.

Лицензия — [GPL-3.0](../LICENSE): код можно брать, менять и распространять,
но собранная на его основе программа тоже должна быть открытой под GPL-3.0.

> ⚠️ **Это урезанная версия: серверов автора в ней нет.** Адреса раздачи
> базы, счётчика запусков и прокси ИИ пустые, и пользоваться серверами автора
> из своих сборок нельзя. Без своих серверов работают законы, поиск, заметки
> и Bodycam — база встроена. Нет обновления базы и ИИ-помощника. Как поднять
> свои — [servers/README.md](../servers/README.md), образцы воркеров там же.

## Что нужно

- Windows 10/11 x64;
- [Node.js](https://nodejs.org) 20 или новее (проверено на 24);
- для Bodycam из исходников — Python 3.14 (см. ниже). Остальное приложение без него работает.

## Запуск и сборка

```bash
cd app
npm install
npm start          # запустить из исходников
npm run dist       # собрать dist/Protocol.exe (portable, один файл)
```

Перед `npm run dist` удалите старую папку `dist`. Сборка сама сжимает базу
(`npm run pack-data` → `data/*.br`) и кладёт службу распознавания в
`resources/voice`.

### ИИ-помощник

Без настройки ИИ выключен, остальное работает. Чтобы включить, нужен **свой**
прокси ИИ — образец и пошаговая инструкция в [servers/README.md](../servers/README.md).
Потом:

1. Скопируйте `ai_config.example.js` в `ai_config.js`.
2. Впишите адрес своего прокси и пароль к нему.

Прокси принимает `POST` с JSON `{system, user, model}` и возвращает
`{text}`. Ключ модели хранится на прокси, в приложение он не попадает.
`ai_config.js` в репозиторий не коммитится.

## Как устроено

| Файл | Что это |
|---|---|
| `main.js` | главный процесс: окна, горячие клавиши, скачивание базы, автообновление, стикеры, окна поверх игры |
| `preload.js` | единственный мост между окнами и главным процессом |
| `lumen.html` | весь интерфейс одним файлом: React 18 + `htm`, без сборщика (не JSX, а шаблонные строки, стиль ES5) |
| `ai_engine.js`, `ai_prompts.js`, `ai_client.js` | путь вопроса к ИИ: оглавление законов → нужные главы + поиск BM25 → ответ → сверка номеров статей с базой |
| `law_loader.js` | загрузка законов: скачанная база из профиля, иначе встроенная `data/` |
| `ai-overlay.html` | быстрый ИИ поверх игры (Alt+Q) |
| `scene-overlay.html` | окно Bodycam поверх игры |
| `voice_brain.js`, `voice_procedure.js` | разбор сцены задержания: этапы, права, сроки, вопросы адвоката — по процессуальному кодексу сервера |
| `voice/` | служба распознавания речи на Python (GigaAM / Whisper, различение голосов) |
| `bodycam_install.js`, `bodycam-manifest.json` | установка среды распознавания по кнопке во вкладке Bodycam |
| `update_apply.js` | подмена `Protocol.exe` при автообновлении (с проверкой SHA-256) |
| `sticker.html` | заметки поверх экрана |
| `data/` | встроенная база законов всех серверов (`{server}.json` + `manifest.json`) |
| `vendor/` | React, ReactDOM, htm — подключаются без сборщика |
| `test/` | проверки (см. ниже) |
| `tools/` | сжатие базы и сборка списка установки Bodycam |

**Схема базы** — общий контракт приложения и парсера: `parts → chapters →
articles`, статья `{num, title, parts:[{n, t}]}`, `num` — строка.

**Главное правило ИИ:** «статьи нет» лучше правдоподобной выдумки. Каждый номер
статьи в ответе сверяется с базой сервера: чужой номер модель исправляет, а если
не смогла — он зачёркивается.

**Звук Bodycam не покидает компьютер.** Распознавание работает на этом ПК —
на второй дорожке звучат голоса других игроков. В ИИ уходит только текст фактов
сцены, без расшифровки чужой речи.

## Bodycam из исходников

Готовая программа ставит среду распознавания сама, по кнопке во вкладке
Bodycam: встраиваемый Python, пакеты и модели, в
`%LOCALAPPDATA%\Protocol\Bodycam`. Из исходников можно использовать её же
(поставьте Bodycam один раз из собранного `.exe`) или своё окружение:

```bash
py -3.14 -m venv ..\voice-env
..\voice-env\Scripts\python.exe -m pip install -r voice\requirements.txt
set PROTOCOL_VOICE_ENV=1
npm start
```

После правки пакетов окружения пересоберите список установки:
`npm run bodycam-manifest`.

## Проверки

```bash
npm run test:ai          # путь вопроса к ИИ, без сети
npm run test:voice       # разбор сцены задержания
npm run test:update      # подмена exe при автообновлении
npm run test:install     # установка Bodycam
npm run test:overlay     # окно Bodycam поверх игры (Electron)
npm run test:focus       # режим «Фокус игры» (Electron)
npm run test:focusback   # возврат фокуса в игру (Electron)
node test/search_bench.js   # качество поиска статей по эталонным наборам
```

`test/ai_eval.js` гоняет живые запросы к ИИ: он тратит деньги на прокси и
без `ai_config.js` не запустится. `test:service` проверяет службу
распознавания и ждёт окружение в `..\voice-env`.

## Если делаете свою сборку

GPL это разрешает. Чтобы ваша сборка не путалась с официальной, поменяйте в
`main.js` адрес обновлений `REPO` и адреса своих серверов, а в `package.json` —
`productName`, `appId` и `name`. Подробно, со всеми «почему», — в
[servers/README.md](../servers/README.md), раздел «Своя сборка».
