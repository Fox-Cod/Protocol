# Как выложить новую версию

1. Удалите папку `app/dist` и соберите: `npm run dist` → `dist/Protocol.exe`
2. Посчитайте сумму: `certutil -hashfile dist\Protocol.exe SHA256`
3. **Releases** → **Draft a new release**, тег версии — как в `package.json` (например `v4.0.1`)
4. Прикрепите `Protocol.exe` — **ровно один** `.exe`: автообновление берёт первый попавшийся
5. В описание — список изменений и SHA-256. Приложение показывает это описание в окне обновления
6. **Не** отмечайте «Pre-release»: такой релиз не считается последним, и автообновление его не увидит

Кнопка «Скачать» и бейдж версии в README берут свежий релиз сами — править их не нужно.
